# AI探险 · 星图冒险

本地运行的 AI 使用记录与能力成长产品。包含世界地图、今日冒险、关卡图鉴、本周战报，以及星匠交互。当前界面采用紧凑布局，适合截图展示。

## 启动

需要 Node.js 20 或更新版本。项目无第三方依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 ，首次运行时自行创建本地账号。

如果端口被占用，可在 PowerShell 中运行：

```powershell
$env:PORT = '4180'
npm start
```

随后打开 http://127.0.0.1:4180 。

## 加载截图演示数据

先在网页创建本地账号，再在项目目录的另一个终端执行：

```sh
npm run demo:load
```

刷新网页后即可看到 5 个模拟项目、20 个关卡和能力成长数据，页面标注“模拟演示”。重复执行不会叠加模拟记录；真实记录保留，加载前会备份本地数据。模拟分析报告只用于界面展示，不代表真实模型评估。

## 上传 GitHub

1. 在 GitHub 创建仓库，例如 `ai-adventure`。
2. 解压压缩包，进入 `ai-adventure-github` 文件夹。
3. 在 GitHub 点击 **Add file → Upload files**，上传文件夹内的文件与子目录，使 `package.json` 位于仓库根目录。
4. 点击 **Commit changes**。

也可在本地初始化 Git 后提交并推送到自己的仓库。

**这是 Node.js 后端产品，GitHub Pages 无法直接运行完整产品。** GitHub 用于保存与分享源码；下载源码后按上面的步骤本地启动。服务仅监听本机回环地址，当前账号、鉴权与日志同步按本地环境设计，尚不适合直接作为公网服务部署。

## 功能与边界

- 本地账号和记录保存在 `data/app.json`，密码采用加盐 scrypt 摘要。
- 重启服务后需重新登录。仅提供首次创建一个账号的入口。
- “接入 Codex”读取运行机器的本地 Codex 日志，不会获取远程账号完整历史。
- AI 结算调用本机 Codex CLI，需安装并登录 CLI；界面先展示发送数据并要求同意。启动和加载模拟数据不会调用模型。
- 模拟数据与真实数据同时存在时，统计会合并；正式使用前建议使用空数据目录重新建号。
- 不要将运行后产生的 `data/`、本地备份或日志提交到 GitHub。

## 目录

- `index.html`、`adventure.css`、`adventure.js`：界面与交互。
- `server.mjs`、`lib/`：本地服务、记录、Codex 日志解析与分析逻辑。
- `demo/records.json`：仅含人工构造的模拟记录，不含账号和密码。
- `scripts/load-demo.mjs`：加载模拟数据。
- `test/`：产品测试。
- `NEXT_VERSION_SPEC.md`、`ROADMAP.md`：随原产品提供的设计资料，具体能力以当前实现为准。

此发布包已排除原账号、测试账号密码、真实会话记录、历史数据备份和运行日志。
